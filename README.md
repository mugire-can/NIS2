# NIS2 Compliance Project — HydroRégie

Practical case study: bringing HydroRégie, a public drinking water utility
serving 450,000 inhabitants and qualified as an *essential entity*, into
compliance with Directive (EU) 2022/2555 (NIS2).

## Structure

| Folder | Block | Deliverable |
|---|---|---|
| `block1-qualification/` | 1 | Regulatory qualification note |
| `block2-gap-analysis/` | 2 | Gap analysis & compliance roadmap |
| `block3-architecture/` | 3 | Segmented IT/OT network architecture |
| `block4-crisis-management/` | 4 | Crisis management chronology & regulatory notifications |
